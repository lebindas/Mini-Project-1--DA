# Mini-Project-1--DA
Mini Project 1- DA

                                                          Spotify Churn Analysis
This project explores Spotify user data to understand customer churn and identify patterns related to user subscriptions and listening behaviour

Used Microsoft Excel Power Query to clean and standardize text data using the Transform → Format options:

Applied Clean to remove non-printable characters.
Applied Trim to remove unwanted spaces.
Applied Capitalize Each Word to standardize text capitalization.
